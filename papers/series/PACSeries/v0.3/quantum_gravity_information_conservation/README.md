# PACSeries Paper 8: Quantum Gravity from Information Conservation

## Overview

This paper derives the Planck scale, black hole thermodynamics, and graviton
properties from the information-theoretic axioms of Dawn Field Theory (DFT) —
PAC conservation and SEC dynamics — **without quantizing general relativity**.
The central claim is that quantum gravity is a *response-time crossover* rather
than a new theory: the regime where perturbation timescales exceed gravitational
negotiation times. The gravitational cascade sits at Fibonacci depth 183, and
the Planck scale, Hawking radiation, the Page curve, the graviton, and the
arrow of time all follow from the cascade structure with zero free parameters.

## Honest Notes

- **~60% of tests are structural** (pass by construction). The 100% score
  reflects internal consistency, not empirical validation. Hard tests await
  LISA, CTA, Euclid.
- **Semi-classical**: perturbations around a cascade background, not full
  non-perturbative quantum gravity (deferred to M12).
- **GW dispersion** is predicted 67 orders of magnitude below the GW170817
  bound — real, but observationally unconstrained with current instruments.
- **Bounce time**: exp_11 computes t_bounce ≈ 1.0 t_P (constant across mass).
  The paper prose (§10.2, abstract) states 0.72 t_P = 1/(2 ln2); that value is
  the minimum cascade tick T_MVAE (exp_03), a distinct quantity. See
  `Code/trace.yaml` (exp_11).
- **Hawking CV**: the T·M coefficient of variation is floating-point noise; the
  canonical snapshot reports 1.7×10⁻¹⁶ (paper prose cites 7.8×10⁻¹⁷, a
  different noise realisation). Both confirm constancy to ~16 significant figures.

## Reproduction

```bash
# from a checkout of the dawn-field-theory repo, with numpy/scipy/matplotlib installed:
cd foundational/docs/preprints/PACSeries/v0.3/quantum_gravity_information_conservation/Code
python reproduce.py --list      # list experiments
python reproduce.py             # run all 13
python reproduce.py 05          # run exp_05 only
```

Fresh runs regenerate timestamped JSON as `results_<TIMESTAMP>.json` next to the
scripts being run (the packaged copies write into `Code/`; the source originals
write into the milestone11 root), plus two empty stub dirs — a consequence of an
argument-order quirk in the milestone's `save_results`; see the "Output location
quirk" note in `reproduce.py`. The frozen, experiment-labelled snapshots used to
write the paper are in `Data/results/`. Figures are regenerated by
`Code/generate_figures.py` from `Data/results/`.

A NumPy-2.0 compatibility shim (`Code/_compat/sitecustomize.py`, auto-loaded via
PYTHONPATH) restores the `np.trapz` alias that NumPy 2.0 renamed to
`np.trapezoid`; exp_04, exp_07 and the shared core still call it. It changes no
numerical result.
