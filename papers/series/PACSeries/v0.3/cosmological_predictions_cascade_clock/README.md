# PACSeries Paper 9: Cosmological Predictions and the Cascade Clock

## Overview

This paper presents the first complete set of beyond-Standard-Model predictions from Dawn Field Theory (DFT), together with the temporal mechanism — the cascade clock — that generates them. Milestone 8 produces 10 pre-registered falsifiable predictions from 2 free parameters (Fibonacci cascade depth 73 and cascade level count *N*). Milestone 9 reduces the free-parameter count to 1 by deriving a cascade clock N(t) = 1.360 + (1/ln φ)·ln(t_lookback) whose slope is fixed by DFT, not fitted, and which unifies the S8, Hubble, and JWST observables into a single temporal function.

## Honest Failures

- **Slope gap (2/4, M9 exp_03):** DFT slope 2.0781 vs free-fit 2.264 (8.9% gap). Monte Carlo places the DFT slope at the 38.6th percentile — within the 95% CI, i.e. noise with only 3 data points (§10.1).
- **DESI w_a tension (3/4, M9 exp_09):** DFT predicts w_a = −0.15; DESI DR1 measures −0.75 ± 0.29 (~2σ). Documented honestly; awaits DR2/DR3 (§10.2).
- **N-universality (3/4, M8 exp_11):** the N range across observables (2.75) exceeds the fixed-N tolerance — resolved by the M9 continuous cascade clock (§10.3, §12.3).

## Reproduction

```bash
# from a checkout of the dawn-field-theory repo, with numpy/scipy/matplotlib installed:
cd foundational/docs/preprints/PACSeries/v0.3/cosmological_predictions_cascade_clock/Code
python reproduce.py --list      # list experiments
python reproduce.py             # run all 22
python reproduce.py m8_07       # run one experiment by id (m8_01..m8_12, m9_01..m9_10)
```

Fresh runs regenerate timestamped JSON into `Code/results/` (the copied scripts' native output location). The frozen snapshot used to write the paper is in `Data/results/`. Figures are regenerated by `Code/generate_figures.py` from `Data/results/`.
