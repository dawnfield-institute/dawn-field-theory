# Data Results

This folder contains JSON results from experiment runs.

## Files

Results are copied from the source experiment folder:
`dawn-field-theory/foundational/experiments/pac_cosmology_validation/results/`

Key result files:
- `exp_03b_jwst_redesigned.json` - Forward predictions (main validation)
- `exp_07_lcdm_comparison.json` - ΛCDM vs PAC comparison
- `exp_08_falsification.json` - Falsification criteria
- `exp_09_expanded.json` - Expanded 10-object analysis
- `exp_10_uhz1_heavy_seeds.json` - UHZ-1 heavy seed analysis

## JWST Catalog

The `jwst_catalog.json` file contains the full observational data for all 10 objects analyzed.

See `Code/trace.yaml` for source file locations.
