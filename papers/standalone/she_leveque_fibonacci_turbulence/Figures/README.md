# Figures

This directory contains publication-quality figures for the She-Leveque Fibonacci paper.

## Required Figures

### Figure 1: prediction_vs_experiment.png
Comparison of Fibonacci predictions against experimental data for p = 1-10.
- X-axis: Structure function order p
- Y-axis: Scaling exponent ζ_p
- Lines: Fibonacci prediction (solid), K41 prediction (dashed), Experimental data (points with error bars)

### Figure 2: fibonacci_decomposition.png
Visual representation of how She-Leveque components map to Fibonacci numbers.
- Flowchart or diagram showing β = F₃/F₄, C₀ = F₃, etc.

## Generation

Figures can be generated from the validation script output.
See `Code/she_leveque_validation.py` for data.
