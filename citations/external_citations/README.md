# External Citations & Foundational References

This directory contains citations for external and foundational works that inform Dawn Field Theory development.

## Contents

- **`external_citations.md`** - Structured list of foundational references organized by topic
- **`citations_bibtex.bib`** - BibTeX entries for all external citations
- **`citations_apa.txt`** - APA-formatted citations for external references

## Purpose

These external citations serve as:
- **Foundational references** for Dawn Field Theory development
- **Background literature** that informs the theoretical framework
- **External validations** and related work in the field
- **Academic context** for the project's theoretical contributions

## Usage

When citing external work in Dawn Field Theory papers or documentation:
1. Check if the reference already exists in `external_citations.md`
2. Use the corresponding BibTeX entry from `citations_bibtex.bib`
3. For new external references, add them to all three files

## Organization

Citations are organized by thematic areas:
- General Information Theory
- Entropy, Thermodynamics, and Computation
- Complex Systems and Emergence
- Recursive Functions, Symbolic Logic, and Computability
- Neural Networks and Cognitive Modeling
- Quantum Cognition and Information Physics
- Geometry, Topology, and Fractals
- Advanced AI and Recursive Theories

## Distinction from Contributor Citations

This directory is separate from the main citation system in `../` which handles:
- Contributor attribution via automated processing
- Pull request citations and project contributions
- Internal project citation management

External citations here are manually curated foundational references that inform the theoretical development of Dawn Field Theory.
