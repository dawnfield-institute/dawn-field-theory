# Archive — Non-Experiment Material

Project material from the 2025 era that is no longer live, kept for lineage rather than
use. Experiments are archived separately, under
[`foundational/experiments/archive/`](../foundational/experiments/archive/README.md).

| Directory | Was | Why it's here |
|---|---|---|
| `devkit-designs/` | `devkit/` | 2025-era architecture design documents — aletheia, brainstem, prometheus, field_decomposition, mcp_server. Despite the name it was never repository tooling (that lives in `tools/`); it is design thinking from the CIMM/QBE period. |
| `todo-2025/` | `todo/` | Planning material across theory, sdk, infra, and biological tracks. Superseded by `roadmaps/` and the milestone structure. |

Neither is maintained. Both are readable as a record of how the project was thinking
before the milestone stack existed — which is the same reason the experiment archive
exists. See [`STANDARDS.md`](../STANDARDS.md) §2.3 for the era definitions.
