# Language to Logic

## Hypothesis
Raw natural language can be converted into structured, executable logic flows based entirely on entropy collapse and recursive segmentation -- without using language models or dictionaries. Character-based Shannon entropy and recursive splitting at maximum entropy differentials can reliably extract semantic roles and logic structures.
