## Question

The reality engine enforces PAC as **one global ledger**: `NormalizationOperator` sums
`E + I + M` over the entire lattice and adds a single uniform scalar correction to every cell.
There is no region that conserves locally, no boundary between regions, no per-region Δ, and
no reconciliation event.

exp_36 Part D derives the cosmic web as the **boundary set of a tiling** of locally-conserving
patches — voids are patch interiors, filaments are boundaries, nodes are multi-boundary
junctions — with Ξ as the coordination cost. `asymmetric_conservation` supplies the machinery:
`P + A + Δ = C`, with Δ the unreconciled boundary buffer and Ξ the reconciliation threshold.

The engine already produces large-scale power (+12.5σ over white noise) and no web geometry
at all (contrast *below* white noise, `is_web` false everywhere). A web is a boundary set;
clumping is what a field does without boundaries.

**Does partitioning the field into patches that conserve locally, with cross-boundary flux
accumulating into Δ and reconciliation firing at Ξ, produce web geometry — voids and
contrast — where the single global ledger produces only clumping?**

The question is *not* whether correlation appears. It is already there. That is what makes
this registrable: the control arm is measured, and the prediction is about geometry.

## Registered invariant

**ξ / L_patch** — correlation length divided by patch scale. Dimensionless, independent of
grid size and of absolute coupling strength.

Not ξ in cells (moves with resolution), not the patch count (moves with grid), not any
absolute coordinate. Per the invariant-registration rule.

## Tests and thresholds

Grid 128 × 32 (the manifold's own shape). Patch scales L ∈ {8, 16, 32} cells along `u`,
giving a 4× range. Five seeds per cell of the design. Control arm = identical configuration
with a single global ledger.

**T1 — Existence.** ξ/L_patch in the patched arm exceeds the single-ledger control by at
least **3× the pooled standard error**, at every one of the three patch scales. Weakest of
the four: the control already sits 6σ above white noise, so a further rise is the least
surprising outcome here and carries the least weight.

**T2 — Geometry. This is the load-bearing test.** The structure is the *boundary set*, so it
tests exp_36 Part D directly:

- **void fraction ≥ 0.30** — control is 0.241 (qp = 0.02), exp_09 measured 0.50
- **density CV ≥ 1.0** — control is 0.661, and *below white noise's 0.741*; exp_09 ~2.0
- **boundary/interior density contrast ≥ 2.0** — no control value exists, because the control
  has no boundaries. This is the one quantity the single-ledger engine cannot express at all.

The first two are exp_09's own thresholds. *Adaptations disclosed*: voids use < 10% of mean
(exp_09's own running-history definition) since a continuous field has no empty cells; the
filament fraction uses an absolute overdensity (M > 2 × mean) because exp_09's percentile
version is tautological on a continuous field, returning 0.25 for a web, a blob and white
noise alike. One rendered frame per condition — including the **isolated low-k component**,
since it was the low-k render that exposed the control's excess power as morphologically
identical to low-passed noise.

**T3 — Scaling.** ξ/L_patch constant to within **±20%** across the three patch scales, while
ξ measured *in cells* varies by ≥ **2×**. If instead ξ in cells is what stays constant, the
patch scale is not what sets the correlation length and Q3 is answered negatively.

**T4 — Ξ (replication, not prediction).** Sweeping the reconciliation threshold across
[0.90, 1.25], structural complexity (density CV) varies **continuously**, with a maximum in
[1.05, 1.07] — spanning both Ξ_analytic = γ + ln φ = 1.05843 and Ξ_discrete = 1 + π/55 =
1.05712 — and **no discontinuity**. Thresholds imported named from fracton, never as bare
literals. A discrete transition would contradict exp_10 in a different substrate and is
reportable either way.

## Kill sentence

> **If patch-local conservation with boundary-Δ reconciliation leaves the field failing T2 —
> void fraction below 0.30 and density CV below 1.0 — across all three patch scales, the
> tiling picture is not what produces web geometry in this substrate, and exp_36 Part D does
> not carry from the cosmological argument to the engine.**

Stated on T2 rather than T1 deliberately. The control already has correlation; a mechanism
that only adds more of it has not demonstrated the claim. **Passing T1 while failing T2 counts
as the kill sentence firing**, because it would mean patches produce clumping like everything
else tried.

## Secondary failure conditions

Any of these voids a positive result:

1. **The global ledger stops closing.** Patch-local conservation must *sum* to the global
   invariant. If the sum over patches of `P + A + Δ` drifts from `C` beyond the engine's
   existing 1e-8 gate, PAC is broken and no ξ result means anything.
2. **Coherence only in diverging runs.** Any condition where `M` leaves the finite range is
   excluded from the analysis and reported as excluded.
3. **Coherence only where Δ is unbounded.** `asymmetric_conservation` requires Δ ∈ [−bound,
   +bound]. If correlation appears only where Δ grows without limit, the mechanism is not the
   registered one.

## Implementation shape

Recorded now so that the thing built is the thing registered.

A `PatchLedgerOperator` giving each patch its own `(P, A, Δ, C)`, accumulating cross-boundary
flux into Δ and reconciling when |Δ| > Ξ. **Reuses `async_pac.AsyncPACNode`** — its
`receive_event` / `reconcile` / `ReconciliationBoundary` are validated 5/5 and are not to be
reimplemented.

Constraints:

- **Fixed tiling in exp_01.** Adaptive or emergent patch boundaries are a second mechanism;
  one at a time. Fixed φ-spaced partition along `u`.
- Must be declared in `src/v3/engine/pipelines.py` (`CANONICAL` or `UNUSED`) or
  `tests/v3/test_pipeline_completeness.py` fails. That gate already caught `PACBalanceOperator`
  going undeclared.
- Every metric used comes from `proof_of_concepts/v4/structure.py` and carries a passing
  `selftest()` with an analytically derived expectation.
- The control arm runs the identical script with patching disabled — not a remembered number
  from an earlier session.

## What a null result is worth

If the kill sentence fires, that is a genuine constraint on the framework rather than a failed
experiment: it would mean the tiling derivation in exp_36, which reduces the cosmological
constant problem to 0.38 orders with zero free parameters, describes a bookkeeping structure
rather than a dynamical one. That is worth knowing precisely because exp_36 is one of the
corpus's strongest results.
