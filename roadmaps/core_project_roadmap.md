# Dawn Field Theory – Core Project Roadmap

This roadmap tracks the main repository's architectural, theoretical, and publication goals. It is updated as the project evolves and links to sub-roadmaps for each major domain.

---

## Implementation Focus (2025)

### **Scaffolded Projects Progress**
Building on validated DFT theory foundations with practical implementations:

**Phase 1 (Current):**
- ✅ **Theoretical Foundation**: Complete SCBF, SEC, QPL, CIMM validation
- 🔄 **Project Scaffolding**: [Detailed architectures in `devkit/projects/`](../devkit/projects/)
  - **Kronos**: Temporal coordination & FDO document architecture
  - **MCP Server**: Model Context Protocol implementation
  - **Prometheus**: Security & monitoring framework
  - **Brainstem**: Cognitive interface & CIP-MCP bridge
  - **Aletheia**: Fractal foundry & component assembly
  - **Field Decomposition**: Entropy analysis toolkit
  - **Fracton**: Distributed execution engine

**Phase 2 (Upcoming):**
- Transition from scaffolding to implementation
- Integration testing with existing DFT stack
- Cross-project coordination and validation
