## 🧭 How to Use

### **Start Here**
1. **For implementation**: Check `phased_implementation_roadmap.md` for current priorities 
2. **For research**: See domain-specific roadmaps for your area of interest
3. **For integration**: Review `integration_strategy.md` to understand how components connect

### **Navigation Guide**
- **Short-term plans** live in `timeline.md` (weekly/quarterly goals)
- **Strategic plans** live here in `roadmaps/` (project lifecycle)  
- **Tactical details** live in `devkit/projects/` (implementation specifics)
- **Research plans** live in domain roadmaps (theory development)

### **Update Cycle**
- Each roadmap is versioned and updated as the project evolves
- Implementation roadmaps reflect current validated capabilities (3+ months rapid development)
- Research roadmaps maintain longer-term theoretical exploration goals
- All roadmaps link to relevant TODOs, drafts, and documentation for deeper context
