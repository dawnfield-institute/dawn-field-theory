# Roadmaps

**The current roadmap is [`ROADMAP.md`](../ROADMAP.md)** at the repository root.

Everything in [`superseded/`](superseded/) is kept deliberately. A roadmap that turned out
wrong is evidence: the April 2026 roadmap forecast *"M12 = Topology Change"*, and M12
became Connection as Primitive. In a corpus that runs on pre-registration, the gap between
what was predicted and what actually happened is part of the record.

| Superseded roadmap | Era | What it planned |
|---|---|---|
| `current_roadmap.md` | 2026-04 | M1–M11 scores, PACSeries v0.3, M12 as "Topology Change" |
| `post_m5_roadmap.md` | 2026-03 | Reality-engine scorecard fixes, entropy-coherence gravity, Papers 9–10 |
| `core_project_roadmap.md` | 2025 | CIP, SCBF, Prometheus, Brainstem, Aletheia, Release 1.0 polish |
| `kronos_roadmap.md` | 2025 | Early Kronos conception, before the vault existed |
| `general_experiments_roadmap.md` | 2025 | Experiment staging, validation and promotion pipeline |
| `math_arithmetic_roadmap.md` | 2025 | Recursive arithmetic spec, base transformation, QBE integration |
| `publication_framework_roadmap.md` | 2025 | Publication runner scripts, CIP tagging, dashboards |

Terminology in the 2025 roadmaps predates PAC/SEC — CIP, SCBF, QPL, CIMM, TinyCIMM and QBE
all appear as live concepts. See [`theory/lexicon.yaml`](../theory/lexicon.yaml) for what
each of them became.
