# 🔬 Field Decomposition: Recursive Entropy Decomposition Framework

## 🧠 How It Works

Field Decomposition operates through recursive filtering and entropy classification:

```
High-Entropy Signal → Bandpass Filtering → Layer Extraction → 
Entropy Classification → Field Reconstruction → Diagnostic Output
```

### Core Process

1. **Signal Analysis**: Parse layered signals with multiple frequency components
2. **Recursive Filtering**: Apply bandpass filters to extract symbolic bands
3. **Entropy Measurement**: Compute normalized Shannon entropy for each band
4. **Classification**: Categorize entropy as E_signal, E_overlap, or E_noise
5. **Field Reconstruction**: Rebuild coherent symbolic structures
6. **Diagnostic Output**: Generate detailed entropy analysis reports
