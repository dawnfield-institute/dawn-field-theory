# Symbolic Superfluid Collapse Pi

## Hypothesis
Symbolic particles within a synthetic superfluid-like field governed by pi-harmonic angular modulation and radial attractor geometry will converge toward a self-organizing rest-state geometry. Symbolic logic structures, entropy, and spatial dynamics converge in a shared system to produce emergent collapse behavior.

## Key Results
- Convergence to radial center is consistent across 5 trials (150 timesteps each, 300 particles, 200x200 grid)
- Symbolic entropy diminishes over time, indicating harmonization
- Transition rules show repeat patterns (D+A: 309, C+D: 302, B+C: 275, A+B: 271), suggesting underlying symbolic logic cycles
- Average speed declines, supporting collapse and stasis
- Forces include radial attraction, pi-harmonic angular bias (sin(pi*theta)), and decaying entropy memory
