# Recursive Tree

## Hypothesis
Entropy alone can generate recursive cognitive geometry. A 3D tree structure grown by recursively splitting from a single origin, using SHA256 hash entropy to guide branching direction, will produce complex brain-like geometry that encodes both structure and symbolic meaning.

## Status
archived

## Key Results
- Recursive structure expands rapidly, doubling at each depth, forming a highly branched symmetric shape
- Each node carries a semantic tag (symbolic embedding), making the structure both geometric and symbolic
- Entropy-driven growth is deterministic and reproducible for each seed
- Emergent complexity: simple rules produce brain-like geometry encoding both memory (structure) and meaning (symbols)
- Validates adaptive pruning as a model for memory selection
- Supports Dawn Field Theory's post-symbolic cognition paradigm
