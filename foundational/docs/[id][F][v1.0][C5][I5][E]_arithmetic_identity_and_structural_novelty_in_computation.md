### Appendix B: Information-Theoretic Formalization

#### Kolmogorov Complexity Measures
For any computational transformation T: X → Y, we can measure novelty as:

```
Novelty(T) = K(Y) - K(X) - K(T)
```

Where:
- K(X) is the Kolmogorov complexity of the input
- K(Y) is the Kolmogorov complexity of the output  
- K(T) is the complexity of the transformation rule

Positive values indicate genuine information creation.

#### Shannon Entropy Analysis
The conditional entropy of outputs given inputs:

```
H(Y|X) = H(X,Y) - H(X)
```

When H(Y|X) > 0, the output contains information not predictable from the input alone, indicating structural novelty.

#### Computational Irreversibility Index
We define an irreversibility index as:

```
I(T) = 1 - P(reconstruct X from Y without T)
```

Where P is the probability of successful reconstruction. Higher values indicate greater novelty generation.
