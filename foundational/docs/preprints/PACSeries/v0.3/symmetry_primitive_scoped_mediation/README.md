## Honest Failures

- **RBF memory damping (M7 exp_08, 2/4):** four activity-based memory models all give positive/near-zero correlation with drive — opposite of the expected 1/(1+αM) damping. Memory may need an information-theoretic definition, not an activity metric (§14.1).
- **Cross-topology symmetry breaking (M7 exp_06, 3/4):** on well-balanced graphs (initial φ-balance ~0.88), weak/random perturbations cannot reliably improve balance; only structured breaks (φ-ratio, 2:1) do (§14.2).
- **Tetration penalty (M6 exp_03, 2/4):** geometric-decay fit R² = 0.67 fails the hardened 0.75 threshold — genuine within-level scatter (§9.3).
- **Neutrino splitting (M6 exp_06, 44%):** uniform Fibonacci spacing gets the hierarchy ordering but not the ratio; improved to 17% in M8 (Paper 9) via PMNS mixing (§14.3).
