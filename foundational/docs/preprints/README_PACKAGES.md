## Package Contents (Schema 2.0 Enhanced)

Each package now contains:

```
package_name/
├── paper.md                    # Main paper (unchanged)
├── README.md                   # Package overview (unchanged)
├── CITATION.md                 # Citation info (unchanged)
├── meta.yaml                   # CIP metadata (unchanged)
├── MECHANISMS.md               # NEW: Paper-specific context
├── UNIFIED_EVIDENCE.md         # NEW: Complete mechanistic chain
├── Code/
│   ├── trace.yaml              # Code traceability
│   ├── requirements.txt        # Dependencies
│   ├── scripts/*.py            # Experiment scripts
│   └── *.py                    # Support modules
├── Data/
│   └── results/*.json          # Experimental results
└── Figures/
    └── *.png, *.pdf            # Publication figures
```

**Total Size**: Typically 200-500 KB (with enhanced docs)
**Overhead**: ~40 KB for MECHANISMS.md + UNIFIED_EVIDENCE.md
