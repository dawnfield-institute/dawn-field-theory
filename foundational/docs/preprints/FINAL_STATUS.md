## 📋 UPLOAD PROCESS (PER PACKAGE)

### Step 1: Go to Zenodo
- https://zenodo.org
- Login with ORCID

### Step 2: Create Upload
- Click "New upload"
- Upload type: Publication → Preprint
- Access: Open Access
- License: AGPL-3.0

### Step 3: Upload Package
- Drag & drop .zip file
- Wait for upload completion
- Verify file size matches

### Step 4: Add Metadata
From .zenodo.json in package:
- Title: [From metadata]
- Creators: Groom, Peter
- Description: [From metadata]
- Keywords: Dawn Field Theory, infodynamics, PAC framework, [specific]
- Related identifiers:
  - GitHub: https://github.com/dawn-field-institute/dawn-field-theory
  - Related DOIs: [if updating existing paper]

### Step 5: Publish
- Click "Publish"
- **IMMEDIATELY copy DOI**
- Update ZENODO_REGISTRY.yaml with:
  ```yaml
  - slug: [paper_name]
    zenodo_record: [number]
    doi: 10.5281/zenodo.[number]
    version: "1.0"
    upload_date: "2025-12-28"
    status: published
  ```

### Step 6: Verify
- Download from Zenodo
- Check SHA256 matches MANIFEST.json
- Verify MECHANISMS.md and UNIFIED_EVIDENCE.md present
- Test: Unzip and spot-check files
