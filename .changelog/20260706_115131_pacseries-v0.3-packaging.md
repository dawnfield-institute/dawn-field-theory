Papers 7–12; no changes to the published v0.1/v0.2 packages.

- Built full reproducibility packages for all six papers: `Code/experiments` (verbatim
  source scripts) + `reproduce.py` + `trace.yaml` + `requirements.txt` +
  `generate_figures.py`, `Data/results`, `Figures/`, `meta.yaml`, `README.md`, `paper.tex`.
